# Snapshot: gamecod_v017 (Версия 0.17)

Дата сохранения: 16 октября 2026 г.
Статус: Полный снимок исходного кода игры и игровой экономики.

## Состав архива
- `src/` — все компоненты интерфейса (React, Lucide icons, Framer Motion), бизнес-логика, хуки, стили и база данных игры.
  - `src/data/gameData.ts` — полная модель экономики (предприятия, уровни, апгрейды, окупаемость, инфраструктурные проекты, недвижимость, транспорт, фондовый рынок, банки).
  - `src/types/game.ts` — типизация TypeScript всех игровых сущностей и сохранений.
  - `src/components/MegacityMap.tsx` — векторная интерактивная карта города с районами, дорогами, рекой, мостами, пульсирующими маркерами предприятий и сбором кассы.
  - `src/components/ToastNotifications.tsx` — системные уведомления, закрепленные внизу экрана устройства с автоисчезновением за 4 секунды и кнопкой-крестиком.
  - `src/components/` — все игровые разделы: Карьера, Автосалон, Гараж, Инвестиции, ТРЦ / Казино, Мегасити, Госдума, Образование, Аналитика и др.
- `package.json` — конфигурация зависимостей и скрипты запуска.
- `tsconfig.json` — параметры компилятора TypeScript.
- `vite.config.ts` — конфигурация сборщика Vite.
- `index.html` — точка входа веб-приложения.
- `metadata.json` — метаданные проекта.
- `firebase-applet-config.json` — конфигурация облачной базы данных Firebase.
